# bit-settled — live SIM demo

**PayPal's merchant negotiation desk for the agent economy.**

A merchant publishes a catalog and private policy; its native agent negotiates with any consumer's personal AI; both sign an Agent Commerce Contract; PayPal settles; a buyer claim is refunded from the merchant reserve in about a second.

This Space runs the **SIM** demo: no keys, no money, all flows deterministic and offline. Click **Run full demo** on the landing page.

- Source: https://github.com/cptlight/bit-settled
- License: Apache-2.0
- Start here: `/start.html`
- 5-step demo: `/demo.html`

The public demo never exposes private merchant floors, and never needs PayPal or AI credentials.
